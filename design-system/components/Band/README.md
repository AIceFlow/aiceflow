# Band

Eine Fläche über die ganze Breite für eine Aussage und eine Handlung. Meist der Schluss einer Seite.

| Variante | Klasse | Grund |
|---|---|---|
| Abgesetzt (Standard) | `af-band` | `well` |
| Papier | `af-band af-band--paper` | `paper` |
| Dunkel | `af-band af-band--ink af-on-ink` | `ink` |

Mitzugeben: Abschnittsmarke, Überschrift `af-band__title` (Gloock `display-l`, höchstens zwei Zeilen), Einleitung, ein Button rechts unten.

- Jede Seite endet mit einem Band in `well`. Höchstens ein Band in `ink` dazu, nie direkt unter dem Einstieg.
- Nie blau, keine Verläufe, keine Fotos dahinter.
