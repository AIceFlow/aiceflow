# Abschnittsmarke

Die kleine Zeile über einer Überschrift, die sagt, wo man gerade ist.

Sie beginnt mit dem kurzen blauen Strich aus dem Signet, der häufigsten Stelle, an der Blau auftaucht. Danach optional eine zweistellige Nummer in `ink`, dann ein Wort in `ink-muted`. Gesetzt in `marker`: Martian Mono, Versalien. Auf `ink`-Flächen färbt `af-on-ink` sie um.

- Eine Marke pro Abschnitt, direkt über der Überschrift, Abstand `space-4`.
- Ein Wort, höchstens zwei. Der Markenname steht nie in der Marke.
- Auf Social-Posts dient sie als Rubrik: „Trace · Woche 46“.

```html
<p class="af-marker"><span class="af-marker__no">03</span> Trace</p>
```
