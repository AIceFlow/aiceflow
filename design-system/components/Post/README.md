# Social-Post

Die Vorlage für LinkedIn und andere Kanäle im Format 4:5.

Drei Arten:

- **Zahl** (`af-post af-post--ink af-on-ink`): eine Zahl aus dem Protokoll in Gloock, der Satzpunkt in `blue`, darunter ein kurzer Satz.
- **Zitat** (`af-post`): ein Zitat in Newsreader kursiv, darunter die Rolle der Person.
- **Satz**: eine Aussage in Gloock, höchstens zwei Zeilen.

Oben eine Abschnittsmarke als Rubrik, unten links das Logo. Dunkle und helle Posts wechseln sich ab.

- Ist der Gloock-Satz länger als zwei Zeilen, kürzen.
- Zitate nur von echten Personen mit deren Zustimmung, Rolle statt Name, wenn gewünscht.
