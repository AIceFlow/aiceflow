# Spalten

Drei Gedanken nebeneinander, getrennt durch Linien statt Karten.

Aufbau: `af-cols` mit drei `af-col`. Je Spalte eine Kennziffer `af-col__no` (Martian Mono, `blue-strong`), ein Titel `af-col__title` (Gloock `display-s`, ganzer Satz), ein bis zwei Sätze `af-col__body`, optional ein stiller Button.

- Immer drei. Bei zwei Punkten lieber ein Absatz, bei mehr als drei eine Liste.
- Keine Karten, keine Schatten, keine Icons.
