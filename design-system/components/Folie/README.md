# Folie

Die Vorlage für Präsentationen im Format 16:9.

Aufbau (`af-slide`, dunkel `af-slide af-slide--ink af-on-ink`): Abschnittsmarke, Titel in Gloock `display-m`, darunter eine Linie und bis zu drei Spalten mit Beschriftung in Martian Mono (`blue-strong`) und Text in Newsreader. Seitenzahl unten rechts.

- Eine Aussage pro Folie. Der Titel ist ein ganzer Satz, höchstens zwei Zeilen.
- Titel- und Kapitelfolien dunkel, Inhaltsfolien hell.
- Das Signet nur auf Titel- und Schlussfolie.
