# Glossar

Welche Wörter wir verwenden, welche wir meiden und was sie bei uns bedeuten. Im Zweifel das deutsche Wort, der englische Begriff höchstens in Klammern dahinter.

## Unsere Begriffe

| Begriff | Bedeutung | Hinweis |
|---|---|---|
| AIceFlow Governance Gateway | Das Produkt: die Kontrollschicht zwischen Agents und Systemen | Bei der ersten Nennung ausschreiben, danach „das Gateway“ |
| AIceFlow Trace | Der Baustein im Gateway, der jede Aktion mitschreibt | Danach „Trace“. Nicht „Logging“, nicht „Monitoring“ |
| Agent | Ein Programm, das mit KI eine Aufgabe erledigt, etwa Rechnungen lesen | Mehrzahl „Agents“. Nicht „Bot“, nicht „KI-Mitarbeiter“ |
| System | Ein Programm des Kunden, an das ein Agent angebunden wird: ERP, Dokumentenablage, Postfach, CRM | Beim Kunden immer mit dessen Namen nennen |
| Anschluss | Die Verbindung des Gateways zu einem System | Lizenziert wird je Anschluss und je Agent |
| Regel | Eine Vorgabe, was ein Agent darf und wann er anhalten muss | „Ihre Regeln“, nie „unsere Regeln“ |
| Freigabe | Ein Mensch stimmt einer angehaltenen Aktion zu | Englisch höchstens: Human in the Loop |
| Protokoll | Die lesbare Liste aller Aktionen in Trace | Einträge sind ganze Sätze |
| Durchgelassen, Angehalten, Freigegeben, Verweigert | Die vier Zustände einer Aktion | Genau diese vier Wörter, keine weiteren |
| Pilot | Der Einstieg: ein Prozess, Festpreis, Parallelbetrieb | „Pilot in 6 bis 8 Wochen“ |
| Parallelbetrieb | Der Agent arbeitet mit, der bisherige Ablauf läuft weiter | Nimmt die Angst vor dem Umstieg |
| Im eigenen Rechenzentrum | Betrieb beim Kunden | Statt „On-Premise“ |
| EU-Cloud | Betrieb in einem Rechenzentrum in der EU | Ohne weitere Dienstleister |

## Wörter, die wir meiden

| Meiden | Stattdessen |
|---|---|
| KI-gestützt, smart, intelligent | sagen, was passiert: „liest“, „prüft“, „trägt ein“ |
| revolutionär, nahtlos, disruptiv, Gamechanger | weglassen |
| MCP, LLM, Tool-Call, Prompt, Token | Gateway, KI-Modell, Aktion, Anweisung |
| Layer, Middleware, Stack | Schicht, Gateway |
| Workflow | Ablauf, Prozess |
| Halluzination | fehlerhaftes Ergebnis |
| On-Premise | im eigenen Rechenzentrum |
| Use Case | Anwendungsfall, Beispiel |
| Discovery-Call | Gespräch |
| Lösung (als Füllwort) | das Gateway, der Agent |
| KI-Mitarbeiter, digitaler Kollege | Agent |
| Compliance-konform, DSGVO-zertifiziert | nur nennen, was nachweisbar ist |

## Schreibweisen

- AIceFlow: immer so, mit großem A, I und F. Im Text einfarbig.
- KI, nicht AI. Ausnahme: der Firmenname.
- E-Mail, nicht Email. ERP, CRM, DMS ohne Erklärung nur im Gespräch mit der IT.
- Beträge: 12.480,00 €. Zahlenbereiche mit „bis“: 6 bis 8 Wochen.
- Uhrzeiten im Protokoll mit Sekunden: 09:14:02.
